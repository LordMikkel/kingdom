# VSCode Dark+

VSCode Dark+ and VSCode Dark Modern+ themes for Zed.

## Installation

1. Open `Command Palette`
2. Select `zed: extensions`
3. Search `VSCode Dark+ Themes`

## Activate Theme

1. Open `Command Palette`
2. Select `theme selector: toggle`
3. Search `VSCode Dark+` or `VSCode Dark Modern+`

## Included Themes

- `VSCode Dark+`
- `VSCode Dark Modern+`
