# names below it (repo, AUR or Flatpak) belong to it.
#   [=id]  fixed: always installed, shown in the summary only (the desktops)
#   [id]   offered in the selector: whole group, then package by package
# Whatever is in no group is the base, always installed: the dotfiles rely
# on it (zsh, ghostty, git, fonts, PipeWire, network, GDM, base tools).
# Drivers are picked separately, for the hardware.
